# Triage labels

This repository has **no label vocabulary** and no external tracker.

- Do not create GitHub/GitLab labels, and do not apply tracker labels.
- Do not use the default `needs-triage` / `needs-info` / `ready-for-agent` /
  `ready-for-human` / `wontfix` strings; they were never adopted here.
- Triage outcomes belong in the ticket's own Markdown: its `Blocked by` line,
  its acceptance checkboxes, and the proposal's status banner. If a ticket needs
  an owner or a decision, state it in prose in that ticket section.
